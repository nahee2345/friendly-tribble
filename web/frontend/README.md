# Wealthy Web Frontend

React + TypeScript + Vite 기반의 인증 후 단일 페이지 앱이다. 투자 계산은 이 프로젝트에서
다시 구현하지 않고 같은 출처의 `/api/v1` FastAPI 응답을 사용한다. 금액과 정밀 소수는 JSON
문자열로 받는다.

## 로컬 개발

현재 운영 기준은 FastAPI가 이 빌드 파일과 API를 `127.0.0.1:8000`에서 함께
제공하는 로컬 동일 출처다. 개발 중에는 프로젝트 루트에서 백엔드를
`127.0.0.1:8000`으로 실행한 뒤 다음을 실행한다.

```bash
cd web/frontend
npm ci
npm run dev
```

브라우저 주소는 `http://127.0.0.1:5173`이다. Vite 개발 프록시는 `/api`만 백엔드로
전달한다. 운영 빌드는 `npm run build`, 테스트는 `npm test`로 실행한다.
운영 접속 주소는 `http://localhost:8000`이며 외부 공개 주소를 사용하지 않는다.

## 보안 경계

- 요청은 same-origin 쿠키를 사용하고 변경 요청은 `wealthy_csrf` 쿠키를
  `X-CSRF-Token` 헤더로 보낸다.
- KIS 키·시크릿은 컴포넌트 메모리에 입력하는 동안만 존재하며 성공·실패 후 지운다.
  브라우저 저장소에는 테마 값만 저장한다.
- PWA·Service Worker·Web Push는 비활성화되어 있다. 과거 Wealthy `/sw.js`
  등록과 `wealthy-static-*` 캐시만 시작 시 정리하고 새 등록은 하지 않는다.
- 알림은 로그인한 웹 내부 알림함과, 사용자가 버튼을 눌러 권한을 허용한
  경우의 페이지-열림 상태 Chrome 알림만 제공한다. Chrome·페이지가 닫히면
  브라우저 알림을 보장하지 않는다.
- 보고서 Markdown은 HTML로 삽입하지 않고 React 텍스트 노드와 단순 표로 렌더링한다.
- 화면의 주문·계좌 조회 기능은 비활성 상태이며 실제 실행 경로가 없다.

## 구현 화면

왼쪽 메뉴에는 요구된 16개 화면이 모두 있다. 대시보드, 포트폴리오 월별 이력,
전략 목표 배분,
전략 카탈로그, 보고서, 자동화 작업 상태, 시장 공급자 상태, 위험 경고, KIS 인증정보 상태,
비밀번호·페이지 열림 알림 설정은 API에 연결한다. 공식 자료·정책·API가 준비되지 않은 계좌/ISA, 세금,
배당, 성과 검증, 종목 검색·분석은 필요한 조건과 함께 비활성 상태를 명시한다.

전략 목표 배분은 8개 비중의 합을 `BigInt` 기반 십진 문자열 계산으로 먼저 확인하지만,
저장 전 최종 검증과 목표 금액 계산은 서버가 한다. 후보 평가용 점수 가중치와는 별도다.
화면은 편집 초안, 저장된 불변 목표, 실제 귀속 비중을 분리하고 실제 자료가
없으면 계산 불가·설정 필요로 표시한다.
