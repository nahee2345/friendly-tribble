## 시각 규칙

- 배경 `#F7F8FA`, 카드 `#FFFFFF`, 기본 글자 `#161B23`, 본문 회색 `#6C7480`, 테두리 `#E5E8ED`
- 블루 `#2563EB`는 강조(선택 메뉴·주요 CTA·선택 차트·실제 보유 종목명)에만 사용합니다.
- 미보유 종목 텍스트는 검정, 수익은 초록 `#0E9873`, 손실은 빨강 `#D84B54`로 나타냅니다.
- 본 시안의 기본 기준 캔버스는 **1600×1000**, 왼쪽 사이드바 **220px**, 헤더 **74px**, 본문 기준 왼쪽 여백 **32px**, 카드 반경 **12px**, 컴포넌트 사이 **16~18px**입니다.
- 상단 제목 약 **31px**, 일반 본문 **15~18px**, 주요 수치 **27~31px**를 시작값으로 사용하고 실제 프레임워크 DPI/접근성에 맞게 보정합니다.
- 기본 화면은 2열/다열, 900px 아래에서는 주요 카드 1열, 1200px 아래에서는 요약 패널 하단 이동, 600px 이하에서는 사이드바 접기 방식을 적용합니다.
- 모든 화면은 스크롤을 지원해야 하며, 폰트 축소만으로 반응형을 구현해서는 안 됩니다.

## 클릭 및 상태 흐름

1. `02_투자전략_비중_설정`의 **전략명 또는 상세보기** 클릭 → `04_전략명_클릭_가치투자_상세` 유형의 전략별 상세로 이동.
2. 슬라이더 드래그·직접 숫자 입력 → 비중 변경·전략 투자금·합계 즉시 재계산; 실제 주문은 발생하지 않음.
3. 저장 조건: 활성화된 각 전략의 비중 범위 0~100%, 합계 **정확히 100%**. 실패 시 회색 비활성화, 부족/초과 수치 안내; 서버에서도 재검증.
4. 기존 저장 포트폴리오 버전은 덮어쓰지 말고 새 버전을 만듭니다. 뒤로 돌아와도 저장되지 않은 편집 상태를 유지합니다.
5. 11번의 목표 도달 예상일은 **신규 투자금, 빈도, 매도 허용, 세금·수수료, 계좌별 제약, 시장가격, 허용 오차**에 따라 계산하고, 계산 불가능하면 `산출 불가`로 표시합니다.
6. 실 보유 종목은 계좌 연동 또는 검증된 사용자 입력으로 판단해야 하며, 그림 속 예시 목록을 사용자 실제 보유라고 가정하지 않습니다.
7. 세금 계산은 2026년 법령·과세 유형·계좌 조건을 공식 자료로 검증 후 적용합니다. 수치 미검증 시 `계산 대기`/`확인 필요` 상태입니다.
8. 한국투자증권 API 인증정보는 OS 비밀 저장소에만 저장하고 로그/ZIP/스크린샷에 실키 또는 계좌번호를 노출하지 않습니다.

## 기획 문서 동기화 지시

- 프로젝트 루트에 반드시 **`UI_DESIGN_SPEC.md`**를 신규 작성하세요. 파일에는 각 PNG의 위치, UI ID, 핵심 요소 규격, 색상 토큰, 클릭 규칙, 유효성, API 연결 상태, 반응형 기준, 접근성 테스트를 명시하세요.
- 각 화면의 기능 요구사항을 기존 `PROJECT_RULES.md`, 기획 명세, 기존 투자 위험 정책에 연결하세요. 기존 문서를 임의 삭제/수정하지 않습니다.
- 기획 명세와 이미지 충돌 시 **기획·안전·세법 규정 우선**, 변경 제안과 승인 여부를 문서로 추적합니다.
- 아이콘/도표/수치는 컨셉 시안이므로 샘플을 실제 라이브 금융 정보로 표시하지 않습니다.
- 구현 결과 스크린샷을 원본 PNG와 나란히 비교해 레이아웃과 동작을 검증하고 차이·미구현 사항을 보고하세요.
- 실거래·매수·매도 주문 실행 기능은 구현하지 않습니다.
